Malviya Nagar, New Delhi, and its creative division **MADS (Music & Dance Studio)**.

## Headline plan

Five independently shippable releases rather than one monolith. **Public launch at the end
of Release 1 (~week 7)** so the site starts generating enquiries while depth, craft, and AI
features continue to ship to a live site.

| Release | Outcome | Est. |
|---|---|---|
| R0 | Foundations — tooling, design system, content model | 1.5–2 wks |
| R1 | Marketing MVP → **live** | 4–5 wks |
| R2 | Faculty, gallery, testimonials, all course pages | 3–4 wks |
| R3 | 3D hero, scroll storytelling, blog, local SEO | 3–4 wks |
| R4 | Grounded AI assistant, staff lead dashboard | 3–4 wks |
| R5 | Student portal (separate approval gate) | TBD |
